# Nexus Front-End UI/UX – README

## Objectif  
Finaliser les maquettes design et intégrer les pages web du site Nexus, en améliorant l'esthétique, l'ergonomie et la performance globale pour une expérience utilisateur fluide et responsive.

---

## Tâches principales

- **Design UI/UX** :  
  Compléter les pages `PROPERTIES`, `BLOG`, `CONTACT` sur Figma en respectant la charte graphique existante.

- **Intégration Front-end** :  
  Convertir les maquettes en code HTML5/CSS3 propre, sémantique et responsive.

- **Optimisation** :  
  Réduire les temps de chargement, tester l'accessibilité et assurer la compatibilité avec tous les navigateurs.

---

## Technologies utilisées

- **Web** : HTML5, CSS3, Media Queries  
- **Design** : Figma (création et édition des maquettes)

---

## User Stories

- UI/UX Designer : Création des pages `Landing`, `Contact`, `Blog`, `Properties` et version responsive.
- Développeur Front-end : Intégration des pages, animations légères, compatibilité cross-browser.
- Responsable performance : Optimisation du code, compression des médias, tests de chargement.
- Équipe projet : Validation de l’accessibilité et de la navigation fluide.

---

## Bonus et recommandations

- Intégration d’une page `Event & Join Tournament`
- Utilisation de BEM, normalize.css, code modulaire et commenté
- Respect des balises HTML sémantiques (`h1` à `h6`, `article`, `section`, etc.)
- Tests d’accessibilité (WAVE, Axe)
- Responsive Design testé sur mobile, tablette et desktop
